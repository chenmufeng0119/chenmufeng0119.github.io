Compute-in-memory (CIM) fabrics built from a single memory technology force a hard trade-off among density, endurance, retention, and compute efficiency. This work examines heterogeneous CIM fabrics that combine complementary memory technologies within one architecture, and analyzes how the resulting design space maps onto efficient and scalable edge inference and on-device learning workloads.
