HD-ViT and ChainCIM co-design a neuro-symbolic vision model and a fused RRAM–eDRAM compute-in-memory architecture for few-shot learning at the edge.

HD-ViT combines a pretrained vision transformer with hierarchical hyperdimensional side memory, binding features from multiple backbone depths into class prototypes for few-shot class-incremental learning.

ChainCIM executes short matrix chains within a fused RRAM–eDRAM macro, reducing intermediate data movement and repeated quantization. The work jointly explores model compression and memory-centric execution to improve efficiency under edge hardware constraints.
